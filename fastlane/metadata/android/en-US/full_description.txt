<p>A read-only Android client for the infrastructure you already run yourself. Porchlight connects to your own Grafana and Portainer instances and shows their current state on your phone — the light you leave on for the stack in the spare room.</p><h2>What it does</h2><ul><li>One glance across every server you add: firing alerts, container state, health checks, and environment availability</li><li>Grafana: server health, version, and active alerts with severity and timestamps</li><li>Portainer: container state, Docker health check results, and offline environments</li><li>A background check every 30 minutes with a low-key notification when something needs attention</li></ul><h2>What it deliberately does not do</h2><p>Porchlight is a viewer, not a monitor. Your existing servers do the watching; this app shows you what they report. It never changes anything on your infrastructure, so it needs no write access to your Grafana or your Docker socket.</p><p>This matters more than it sounds. A phone cannot monitor reliably: Doze mode, background execution limits, and aggressive battery optimisation all stop it. So instead of pretending otherwise, Porchlight shows you the signal your infrastructure actually produces, and is explicit about how fresh it is.</p><h2>Privacy</h2><ul><li>No account, no sign-up, no analytics, no crash reporting</li><li>No network requests to anything except the servers you configure</li><li>Credentials are encrypted on-device with the Android Keystore</li><li>Nothing is stored on a Kituwa IT server, because there isn't one</li></ul><h2>Honest about silence</h2><p>Porchlight is built around one rule: never let cached data look current.</p><ul><li>If a server cannot be reached, it says so and never reports "All clear"</li><li>Unreachable servers are counted as a problem, not a neutral one</li><li>The last successful check is timestamped separately, so a server that has been down for days cannot pretend it was just verified</li><li>A Grafana whose token cannot read alerts says "unavailable", not "0"</li><li>The detail screen states plainly that current state is unknown, and that silence does not mean everything is fine</li></ul><h2>Private and self-signed certificates</h2><p>Porchlight accepts certificates signed by a private or self-signed authority, which is the normal situation for a reverse proxy or Portainer's own HTTPS listener. Install the CA certificate once, using the certificate your server already offers, and the certificate validates normally from then on. There is no "ignore certificate errors" option, because accepting an unverified certificate removes the protection TLS provides against someone on your network. Plain HTTP works too, for services on a LAN or VPN.</p><h2>Getting started</h2><p>For Grafana, create a service account token under Administration, then Users and access, then Service accounts. Give it the Viewer role and the <code>alerts:read</code> permission. For Portainer, use your ordinary username and password and Porchlight will exchange them for a short-lived token. Plain HTTP works, so a reverse proxy with a self-signed certificate is fine.</p><h2>Who made this</h2><p>Brought to you by Kituwa IT.
